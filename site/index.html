Methodology

How this research is produced

Process

  1. Read the 100-app catalogue.
  2. Search official documentation, authentication and MCP sources.
  3. Fetch and validate relevant pages.
  4. Extract only supported facts.
  5. Save each result incrementally and export dashboard data.

Limitations

  • Credentials are not tested through account sign-up.
  • Partner pricing may remain Unknown.
  • JavaScript-only documentation may not be readable.
  • Buildability is a rubric-based judgment.
